# 🎓 Student Result Analyzer

A beginner-friendly Java console application that analyzes a student's academic result.

## 📌 Project Overview

The **Student Result Analyzer** is a Java-based console program that accepts marks for five subjects and generates a simple academic result.

The program calculates the student's:

* Total marks
* Percentage
* Grade
* Pass/Fail status
* Highest subject mark

This project was created as part of my **Java programming practice and GitHub learning journey**.

## 🎯 Objective

The main objective of this project is to practice basic Java programming concepts by implementing them in a small real-world application.

## 🛠️ Technologies Used

* Java
* VS Code
* Git
* GitHub

## 🧠 Java Concepts Practiced

This project helped me practice:

* `Scanner` for user input
* Variables and data types
* Arithmetic operators
* Relational operators
* Logical operators
* `if-else` statements
* Nested conditions
* Boolean values
* Ternary operator
* `Math.max()`
* Console output

## ⚙️ How It Works

1. The user enters the student's name.
2. The user enters marks for five subjects.
3. The program calculates the total marks.
4. The percentage is calculated.
5. The program checks whether the student has passed all subjects.
6. A grade is assigned according to the percentage.
7. The highest mark among the subjects is identified.
8. The final result is displayed in the console.

## 📊 Grading System

| Percentage            | Grade |
| --------------------- | ----- |
| 90% and above         | A+    |
| 80% – 89%             | A     |
| 70% – 79%             | B     |
| 60% – 69%             | C     |
| Below 60%             | D     |
| Failed in any subject | F     |

# 🏧 ATM Simulation System

A console-based ATM Simulation System developed using Java.

## 📌 Project Overview

The **ATM Simulation System** is a simple Java application that simulates basic ATM operations through a console menu.

The user can check their balance, deposit money, withdraw money, and exit the system.

This project is part of my Java programming practice and GitHub learning journey.

## 🎯 Objectives

The main objective of this project is to understand how multiple Java concepts can be combined to create a small real-world application.

## ✨ Features

* Check account balance
* Deposit money
* Withdraw money
* Insufficient balance validation
* Invalid amount validation
* Menu-driven interface
* Continuous operations until the user exits

## 🛠️ Technologies Used

* Java
* VS Code
* Git
* GitHub

## 🧠 Java Concepts Practiced

This project helped me practice:

* Variables and data types
* `Scanner`
* Methods
* Parameters and arguments
* `if-else`
* `switch`
* `do-while` loop
* Arithmetic operators
* Relational operators
* Logical conditions
* `static` methods
* Input validation

## ⚙️ How It Works

1. The program starts with an initial balance.
2. An ATM menu is displayed.
3. The user selects an operation.
4. The selected operation is performed.
5. The balance is updated after deposit or withdrawal.
6. The system validates invalid amounts and insufficient balance.
7. The menu continues to appear until the user selects Exit.

## 💡 Example Operations

```text
1. Check Balance
2. Deposit Money
3. Withdraw Money
4. Exit
```
