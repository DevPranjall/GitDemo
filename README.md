# 🎓 Student Result Analyzer

A beginner-friendly Java console application that analyzes a student's academic result.

## 📌 Project Overview

The **Student Result Analyzer** is a Java-based console program that accepts marks for five subjects and generates a simple academic result.

The program calculates the student's:

* Total marks
* Percentage
* Grade
* Pass/Fail status
* Highest subject mark

This project was created as part of my **Java programming practice and GitHub learning journey**.

## 🎯 Objective

The main objective of this project is to practice basic Java programming concepts by implementing them in a small real-world application.

## ⚙️ How It Works

1. The user enters the student's name.
2. The user enters marks for five subjects.
3. The program calculates the total marks.
4. The percentage is calculated.
5. The program checks whether the student has passed all subjects.
6. A grade is assigned according to the percentage.
7. The highest mark among the subjects is identified.
8. The final result is displayed in the console.

## 📊 Grading System

| Percentage            | Grade |
| --------------------- | ----- |
| 90% and above         | A+    |
| 80% – 89%             | A     |
| 70% – 79%             | B     |
| 60% – 69%             | C     |
| Below 60%             | D     |
| Failed in any subject | F     |
